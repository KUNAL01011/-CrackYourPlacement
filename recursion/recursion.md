# Recursion

-> Don't think about all the recursive calls. Trust that the recursive call solves a smaller version of the problem. Your job is only to solve the current step.

-> stop thinking how the recursion work think if someone solve the problem magically how you solve the current step

-> Every Recursion has only three Problems 
  1. What is my function supposed to return?
  2. What is the smaller problem?
  3. After recursion returns, what remains?
