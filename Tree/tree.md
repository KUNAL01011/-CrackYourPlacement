# Tree
-> tree is a non-linear data structure used to represent hierarchical relationship between elements

# key terminology
-> Node, Root Node, Parent Node, Child Node, Leaf Node, Edge Node etc

# Type of Tree

## Binary Tree
  -> Full Binary Tree : 0 or 2 children
  -> Complete Binary Tree : Filed Level by Level
  -> Perfect Binary Tree : All Level full
  -> Skewed Tree : Like a Linked List

## Binary Search Tree
  -> Left Node < Root Node < Right Node

## Self Balancing Tree
  -> AVL
  -> Red black Tree

## Heap Tree
  -> Min Tree
  -> Max Tree

## String / Dictionary Tree
  -> Trie

## Multi Way Tree
  -> B Tree
  -> B+ Tree

## Special / Advanced 
  -> Segment Tree
  -> Fenwink Tree
  -> N-ary Tree
  -> Suffix Tree
